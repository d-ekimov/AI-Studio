AI Studio — готовый набор файлов для GitHub Pages.

1. Скачай архив и распакуй.
2. Загрузи содержимое папки в корень репозитория GitHub (не сам ZIP).
3. Подтверди замену index.html, styles.css и app.js.
4. Проверь, что manifest.json, service-worker.js и папка icons тоже загружены.
5. Открой Settings → Pages и проверь источник публикации. Подожди обновления сайта; старый кэш может сохраняться.

Работают: навигация, демо-чат, сравнение, проекты, задачи, страница подключений и базовая PWA-установка.
Важно: настоящие API не подключены. Никогда не вставляй ключи в публичный HTML/JS. Для интеграций нужен сервер.
